# Contributing

Thanks for your interest in improving this project.

## Setup

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-change`
3. Install dependencies: `pip install -r requirements.txt`
4. Run the framework: `python main.py --verbose`

## Development Guidelines

- Keep code modular and beginner-friendly
- Add clear docstrings for functions
- Preserve CLI compatibility for existing options
- Ensure `python main.py` works before opening a PR

## Pull Request Checklist

- [ ] Code runs without errors
- [ ] Changes are documented in `README.md` if needed
- [ ] New behavior is explained clearly in PR description
